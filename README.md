## Overview

ANALA is a full-stack AI conversational platform designed around a separate frontend and backend architecture. The project is maintained across two independent repositories:

- **ANALA Client** — React-based frontend responsible for the user interface, authentication state, conversations, message rendering, profile management, and overall application experience.
- **ANALA Server** — Java Spring Boot backend responsible for authentication, conversation management, message persistence, database operations, and AI integration.

This repository acts as the central project repository, containing documentation and links to both application repositories.

## Features

### AI Conversations

ANALA provides an interactive conversational interface for communicating with an AI assistant. Users can:

- Send prompts to the AI
- Receive AI-generated responses
- Continue existing conversations
- Maintain multiple conversations
- Persist conversation history
- Return to previous conversations

The backend retrieves the existing conversation history before generating a response, allowing the AI to maintain conversational context.

### Conversation Management

ANALA provides complete conversation management functionality. Users can:

- Create conversations
- View active conversations
- View archived conversations
- Update conversation titles
- Pin conversations
- Unpin conversations
- Archive conversations
- Restore conversations
- Delete conversations

Conversation titles can also be automatically generated by the AI after the first response.

### Persistent Message History

Every conversation contains persistent messages stored in PostgreSQL. Messages are associated with:

- User conversation
- Message role
- Message content
- AI model information where applicable
- Creation timestamp

Supported message roles include:

```text
USER
ASSISTANT
SYSTEM
```

## Tech Stack

**Frontend:** React.js, Tailwind CSS, Zustand
**Backend:** Java, Spring Boot, Spring Security, Spring Data JPA, Hibernate
**Database:** PostgreSQL
**Caching:** Redis
**Auth:** JWT-based authentication
**Infrastructure:** Docker, Vercel (client), Railway (server)
